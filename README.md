#Python Basics
This repository contains basic Python programs to practice and learn fundamental programming concepts.
It includes simple exercises to help beginners get comfortable with Python.
📝 Programs Included
Basic Calculator – Perform addition, subtraction, multiplication, and division
Even or Odd Checker – Check if a number is even or odd
Divisibility Checker – Check if a number is divisible by another
Prime Number Checker – Check if a number is prime
